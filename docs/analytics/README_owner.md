# Инструкция для владельца: обновить дашборд (v2, без формул)

> Ничего устанавливать не нужно. Никакого терминала, git и Python.
> Всё — в браузере, в вашей Google-таблице.

Таблица: <https://docs.google.com/spreadsheets/d/1enDTD3AoRE5_baxZma_fEZ4SXq2Nk2ojAz8yteIDskI/edit>

**Что нового в v2:** в таблице больше нет ни одной формулы — все числа уже посчитаны.
Поэтому ошибки `#ERROR!` (они были из-за локали таблицы) больше не появляются.

---

## Шаг 1. Открыть редактор скриптов
1. Откройте таблицу.
2. Верхнее меню → **Расширения** → **Apps Script**.
3. Откроется вкладка с редактором и файлом `Code.gs`.

## Шаг 2. Заменить код
1. В редакторе выделите весь текст в `Code.gs` (Ctrl+A) и удалите.
2. Вставьте **весь** текст файла [`build_dashboard.gs`](./build_dashboard.gs)
   (аналитик пришлёт файл; можно скопировать содержимое целиком).
3. Нажмите 💾 **Сохранить** (Ctrl+S).
4. Закройте вкладку редактора.

## Шаг 3. Вернуться в таблицу
1. Обновите страницу (F5).
2. В верхнем меню появится **«Аналитика Good Family»**.
   Если не появилось — обновите ещё раз и проверьте, что код сохранён.

## Шаг 4. Пересобрать дашборд
1. Меню **«Аналитика Good Family»** → **«Настроить / обновить дашборд»**.
2. Google может снова спросить авторизацию (как в первый раз):
   **«Продолжить»** → при предупреждении **«Дополнительно»** →
   **«Перейти на страницу проекта (небезопасно)»** → **«Разрешить»**.
3. Если попросит секрет — вставьте тот же секрет аналитики, что и в первый раз
   (он мог сохраниться; тогда окно не появится).
4. Подождите 20–60 секунд → «Дашборд собран».

**Важно:** запускать «Настроить / обновить дашборд» можно сколько угодно раз.
Скрипт сам:
- снимает старые защиты листов;
- очищает «Дашборд» и служебные листы (старые `#ERROR!` исчезнут);
- удаляет старые графики и рисует новые;
- проверяет, что старый ежечасный триггер не дублируется, и пересоздаёт его.

## Что должно получиться
- **«Дашборд»**: 4 KPI-карточки, таблица «Хорошие дела / сад / достижения»,
  воронка и охват, блок «Качество данных» (7 проверок), топ-10 приложений,
  блок «Чего пока нет» и 4 графика.
- Служебные листы: «Сырые данные» (скрыт), «Функции», «История», «Достижения»,
  «Приложения», «_Служебный» (скрыт — там время/статус обновления).
- Данные обновляются **каждый час** автоматически.

## Если что-то не так
| Симптом | Что сделать |
|---|---|
| Остались `#ERROR!` | Вы всё ещё на старом коде v1. Повторите шаги 2–4 и запустите «Настроить / обновить дашборд». |
| **«Exception: Cannot call SpreadsheetApp.getUi() from this context. onOpen»** | **Это не поломка.** Такая запись появляется в журнале «Выполнения» редактора Apps Script, потому что при установке скрипта у него нет доступа к интерфейсу таблицы. Меню в самой таблице при этом появляется нормально. В новой версии скрипта эта ошибка перехватывается и в журнале будет строка `onOpen: пропущено меню (нет UI-контекста)` — тоже можно игнорировать. |
| Нет меню «Аналитика Good Family» | Обновите страницу таблицы (F5) и подождите 2–3 секунды. Если не появилось: в редакторе Apps Script выберите функцию `onOpen` и нажмите «Выполнить» — это нормально, ошибки нет; затем вернитесь в таблицу и обновите страницу. |
| «Секрет не задан» | Меню → «Настроить / обновить дашборд» → вставьте секрет. |
| «Ошибка: HTTP 403» | Секрет неверный/устарел — попросите новый. |
| «Не удалось получить данные» | Меню → «Обновить данные сейчас»; если повторяется — сервер аналитики недоступен, сообщите разработчику. |
| Цифры не меняются | Нажмите «Обновить данные сейчас». Google запускает триггеры с задержкой до 15 минут. |
| Нет какого-то графика | Меню → «Настроить / обновить дашборд». Если график не появился — на скрытом листе `_Служебный` в ячейке `F2` будет причина. |
| Кто-то поправил листы вручную | Меню → «Настроить / обновить дашборд» — всё перезапишется. |

> **Про журнал «Выполнения».** Красные строки с `Exception` при установке —
> это нормально для Apps Script: функции `onOpen`, `installMenu` и запрос секрета
> требуют открытой таблицы. Запускайте действия **из меню таблицы**, а не кнопкой
> «Выполнить» в редакторе — тогда ошибок не будет.

## Чего не делать
- Не удаляйте и не переименовывайте листы: «Дашборд», «Сырые данные», «Функции»,
  «История», «Достижения», «Приложения», «_Служебный».
- Не публикуйте секрет в чатах и на листах — он хранится в свойствах скрипта.
- Лист `Лист1` (если остался от старой таблицы) скрипт не трогает — его можно удалить вручную.
