# Инструкция для владельца: собрать дашборд за 5 минут

> Ничего устанавливать не нужно. Никакого терминала, git и Python. Всё — в браузере,
> в вашей Google-таблице.

Таблица: <https://docs.google.com/spreadsheets/d/1enDTD3AoRE5_baxZma_fEZ4SXq2Nk2ojAz8yteIDskI/edit>

## Шаг 1. Открыть редактор скриптов
1. Откройте таблицу.
2. Верхнее меню → **Расширения** → **Apps Script**.
3. Откроется новая вкладка с редактором и файлом `Code.gs`.

## Шаг 2. Вставить код
1. В редакторе выделите весь текст в `Code.gs` (Ctrl+A) и удалите.
2. Вставьте туда **весь** текст файла [`build_dashboard.gs`](./build_dashboard.gs)
   (файл пришлёт аналитик; можно открыть и скопировать через «Скачать»/просмотр).
3. Нажмите 💾 **Сохранить** (Ctrl+S).
4. Закройте вкладку с редактором.

## Шаг 3. Вернуться в таблицу
1. Обновите страницу таблицы (F5).
2. В верхнем меню появится новый пункт **«Аналитика Good Family»**.
   Если не появился — обновите страницу ещё раз и проверьте, что код сохранён.

## Шаг 4. Запустить сборку
1. Меню **«Аналитика Good Family»** → **«Настроить / обновить дашборд»**.
2. Google покажет окно авторизации — это нормально для первого запуска:
   - нажмите **«Продолжить»** / выберите свой аккаунт;
   - если появится «Google не проверил это приложение» — **«Дополнительно»** →
     **«Перейти на страницу проекта (небезопасно)»**;
   - нажмите **«Разрешить»**.
3. В появившемся окне вставьте **секрет аналитики** (выдаётся отдельно) и нажмите **OK**.
   Секрет сохранится внутри скрипта и не появится ни на одном листе.
4. Подождите 20–60 секунд. Появится сообщение «Дашборд собран».

## Что должно получиться
- Лист **«Дашборд»** — KPI-карточки, таблицы, 4 графика, блок «Качество данных».
- Служебные листы: «Сырые данные» (скрыт), «Функции», «История», «Достижения»,
  «Приложения», «_Служебный» (скрыт).
- Данные обновляются **каждый час** автоматически; вручную ничего делать не нужно.

## Если что-то пошло не так
| Симптом | Что сделать |
|---|---|
| Нет пункта меню «Аналитика Good Family» | Обновите страницу таблицы; проверьте, что код в `Code.gs` сохранён (💾). |
| «Секрет не задан» | Меню → «Настроить / обновить дашборд» → вставьте секрет ещё раз. |
| «Ошибка: HTTP 403» | Секрет неверный/устарел — попросите новый. |
| «Не удалось получить данные» | Нажмите меню → «Обновить данные сейчас»; если повторяется — сообщите разработчику (сервер аналитики недоступен). |
| Цифры не меняются | Нажмите «Обновить данные сейчас». Google обновляет триггеры с задержкой до 15 минут. |
| Кто-то случайно изменил листы | Меню → «Настроить / обновить дашборд» — он пересоберёт всё заново. |

## Чего делать НЕ нужно
- Не удаляйте и не переименовывайте листы: «Дашборд», «Сырые данные», «Функции»,
  «История», «Достижения», «Приложения», «_Служебный».
- Не редактируйте «Дашборд» руками — формулы перезапишутся при обновлении.
- Не публикуйте секрет в чатах/на листах. Он уже хранится в свойствах скрипта.

## Если нужен вариант «по ТЗ» с IMPORTDATA
Тот же результат можно получить формулами `IMPORTDATA` (без скрипта и без триггера):
подробности — в [`sheet_layout.md`](./sheet_layout.md), раздел «Ручной режим (IMPORTDATA)».
Но скрипт удобнее: секрет не лежит на листах и обновление идёт по расписанию.
