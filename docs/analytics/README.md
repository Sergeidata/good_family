## Как это должно работать (после доступа)

1. Владелец выполняет 4 шага из `README_owner.md` (Apps Script → вставить код →
   сохранить → меню «Аналитика Good Family» → «Настроить / обновить дашборд»).
2. Скрипт за один запрос на срез тянет CSV с `http://89.108.66.36/export_stats`
   и раскладывает по листам: «Сырые данные», «Функции», «История», «Достижения»,
   «Приложения». «Дашборд» считается формулами.
3. Триггер `refreshDashboard` обновляет данные каждый час; формулы пересчитываются сами.
4. Секрет хранится только в `PropertiesService` (ввод — один раз в диалоговом окне).

Если у аналитика появится реальный способ писать в таблицу (например, сервисный аккаунт
с доступом к таблице и JSON-ключ), тот же набор данных можно залить через Sheets API —
структура уже описана в `sheet_layout.md`, но Apps Script-путь остаётся основным:
владельцу не нужно ничего устанавливать.

## Ожидаемые листы (7)

1. **Дашборд** — KPI, функции, воронка, качество данных, 4 графика, ограничения.
2. **Сырые данные** (скрыт) — `metric,value` за вчера.
3. **Функции** — `feature,yesterday,total` + отсортированный хелпер `D:E`.
4. **История** — `date,active_members,active_families,syncs,tasks_done,achievements` (скрытые хелперы `G:I`).
5. **Достижения** — `achievement_key,period,count` (сейчас пусто).
6. **Приложения** — `app,minutes_yesterday` + предупреждение о недостоверности.
7. **_Служебный** (скрыт) — обновление, дата данных, статус, диагностика, опциональные URL для IMPORTDATA.
