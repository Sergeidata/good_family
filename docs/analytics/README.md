## Что делает v2 при запуске

1. Спрашивает секрет (один раз, хранит в Script Properties — на листах его нет).
2. Забирает 5 CSV: `summary`, `features`, `daily&days=90`, `achievements`, `top_apps`.
3. Снимает защиты со всех управляемых листов, очищает и перезаписывает их значениями.
4. Считает в JS: KPI, проценты воронки, среднее участников на семью, статусы качества.
5. Пересобирает «Дашборд»: 4 KPI, функции, воронку, качество (7 проверок), топ-10 приложений,
   ограничения и 4 графика. Даты пишутся текстом с форматом `@`.
6. Пересоздаёт ежечасный триггер `refreshDashboard` (старый удаляет, дублей нет).
7. При ошибке загрузки не ломает дашборд: пишет статус в `_Служебный!B5/F2`,
   в `Дашборд!A2` — «ОШИБКА обновления», старые значения сохраняются.

## Почему v2 не сломается от локали

Формул нет вообще: ни `VLOOKUP`, ни `IFERROR`, ни `SORT/FILTER`, ни `ARRAYFORMULA`.
Разделителей аргументов нет — парсить нечего. Текст собирается в JS-строках,
числа пишутся как числа. Дата — ISO-строка с форматом ячейки `@`, чтобы Google не
превращал её в datetime.
