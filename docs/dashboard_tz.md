# ТЗ: дашборд аналитики Good Family в Google Sheets

## Источник данных

Единственный источник — **уже готовый endpoint**, БД напрямую не трогать.

```
http://89.108.66.36/export_stats?secret=<SECRET>&format=csv&table=<TABLE>
```

`SECRET` = значение `EXPORT_STATS_SECRET` из `/opt/goodfamily/.env` (выдаётся отдельно).

| `table` | Что отдаёт | Колонки |
|---|---|---|
| `summary` | KPI за вчера | `metric,value` |
| `features` | популярность функций | `feature,yesterday,total` |
| `daily` | история по дням (`&days=30`) | `date,active_members,active_families,syncs,tasks_done,achievements` |
| `achievements` | топ достижений | `achievement_key,period,count` |
| `top_apps` | топ приложений за вчера | `app,minutes_yesterday` |

Без `format=csv` тот же URL отдаёт JSON (для отладки).

## Структура таблицы

### Лист 1 «Дашборд» (для пользователя, не редактировать руками)

**Блок A — три KPI-карточки (за вчера):**

```
A1: Активные семьи
A2: Активные пользователи
A3: Топ-функция
```

Формулы:
```
B1: =VLOOKUP("active_families_yesterday",'Сырые данные'!A:B,2,FALSE)
B2: =VLOOKUP("active_members_yesterday",'Сырые данные'!A:B,2,FALSE)
B3: =INDEX(FILTER('Функции'!A2:A,'Функции'!B2:B=MAX('Функции'!B2:B)),1)
```

**Блок B — динамика за 30 дней** (линейный график):
- X: `'История'!A2:A`
- Серии: `'История'!B` (активные пользователи), `'История'!C` (активные семьи)

**Блок C — популярность функций** (столбчатая диаграмма):
- Данные: `'Функции'!A2:A` → `'Функции'!B2:B`
- Отсортировать по убыванию

**Блок D — воронка продукта:**
```
Создано семей      | =VLOOKUP("total_families",...)
Из них с задачами  | =COUNTIF('Функции'!B2:B10,">0")
Достижения         | =VLOOKUP("achievements_yesterday",...)
```

**Блок E — топ приложений** (топ-10, где дети проводят время).

## Автообновление

`IMPORTDATA` обновляется сама примерно **раз в час** — этого достаточно.

Если нужен принудительный refresh: `Расширения → Apps Script`:

```javascript
function refreshDashboard() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  // Пересоздаём важные листы — форсирует перезагрузку IMPORTDATA
  ['Сырые данные', 'Функции', 'История'].forEach(name => {
    const sheet = ss.getSheetByName(name);
    if (!sheet) return;
    const formula = sheet.getRange('A1').getFormula();
    if (formula) {
      sheet.getRange('A1').clearContent();
      spreadSheetApp.flush();
      sheet.getRange('A1').setFormula(formula);
    }
  });
}
```

Триггер: `По времени → Каждый час`.

## Определения метрик (важно для корректных подписей)

| Метрика | Определение |
|---|---|
| **Активная семья** | семья, у которой хотя бы один участник синхронизировался за день (`screen_time.family_id`) |
| **Активный пользователь** | участник, у которого была синхронизация за день (экранное время или задача) |
| **Хорошие дела** | `tasks`: `created` → создано, `done_at` → выполнено ребёнком, `approved_at` → подтверждено родителем |
| **Достижения** | `achievements.earned_date` |
| **Семейный сад** | `garden.updated_at` — изменение уровня/прогресса |
| **Награды** | `reward_requests.created_at` |

## Что важно учесть

1. **Данных пока мало** (7 семей, 11 участников). Дашборд будет выглядеть «пусто» — это нормально, не баг.
2. **`achievements` = 0** — достижения ещё никто не заработал. Метрика есть, но пустая.
3. **`garden` = 0** — сад не используется.
4. **Данные «за вчера»** — endpoint всегда считает по вчерашнему дню (UTC). Сегодняшние данные появятся завтра.
5. **Секрет не публиковать** — он даёт доступ ко всей аналитике. Лист с URL лучше скрыть или защитить.

## Полезные дополнительные срезы (на усмотрение аналитика)

Если будет время и данные, стоит добавить:

- **Retention:** доля участников, вернувшихся на 2-й/7-й день
- **Среднее число участников на семью**
- **Конверсия:** создал семью → пригласил второго → выполнена первая задача
- **DAU/WAU/Monthly** — соотношение
- **Топ достижений** (лист «Достижения» уже есть)
- **Распределение времени в приложении** по дням недели — «в какие дни семья больше смотрит в телефон»
